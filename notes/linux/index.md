## Tại sao học Linux?

Linux là nền tảng của hầu hết các server, container và cloud infrastructure. Hiểu Linux giúp bạn:

- Debug vấn đề trên server nhanh hơn
- Tối ưu hiệu năng hệ thống
- Tự động hóa công việc bằng shell script
- Làm việc hiệu quả với Docker và Kubernetes
